# Heavy ML/OCR packages — installed in a SEPARATE Docker layer so they are
# cached independently of the light packages above.
#
# ⚠️  PyTorch CUDA vs CPU:
#     By default, `pip install torch` downloads the FULL CUDA version (~2.5 GB of
#     nvidia GPU libraries). Since this project runs on CPU-only servers (Docker,
#     no GPU), we pre-install the LIGHTWEIGHT CPU-only torch first (~180 MB).
#     When docling is installed next, pip sees torch is already satisfied and
#     skips re-downloading the GPU version. Total savings: ~2.3 GB per build.
#
--extra-index-url https://download.pytorch.org/whl/cpu

# Then the heavy ML stack (uses the CPU torch installed above)
